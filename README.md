# ASCII Video Player

Скрипт для воспроизведения видео в терминале с использованием цветных символов ASCII.

## Возможности
- Отображение видео в реальном времени с поддержкой True Color.
- Автоматическое изменение размера окна терминала под формат видео.
- Возможность ограничения частоты кадров (FPS).
- Режим бесконечного повтора воспроизведения.
- Очистка терминала после завершения работы.

## Требования
Для работы требуются Python 3 и установленные библиотеки:
- opencv-python
- numpy

## Установка
Выполните команду для установки необходимых компонентов:
pip install opencv-python numpy --break-system-packages

## Использование
Базовый запуск с автоматическим изменением размера окна:
python3 main.py путь_к_видео.mp4

Запуск с ограничением частоты кадров до 15 FPS:
python3 main.py video.mp4 --fps 15

Запуск с зацикливанием видео:
python3 main.py video.mp4 --loop

Запуск без автоматического изменения размера окна:
python3 main.py video.mp4 --no-resize

## Управление
Для выхода из режима просмотра и остановки скрипта нажмите сочетание клавиш Ctrl+C.
