# ASCII Video Player

Скрипт для воспроизведения видео в терминале с использованием цветных символов ASCII.

## Описание

Этот проект позволяет просматривать видео прямо в терминале, конвертируя каждый кадр в цветной ASCII-арт. Поддерживает True Color для точной цветопередачи, автоматическое изменение размера окна терминала и различные опции воспроизведения.

## Возможности

- **Цветной ASCII-арт**: Использование True Color для отображения видео в терминале.
- **Автоматическое масштабирование**: Адаптация размера окна терминала под формат видео.
- **Ограничение FPS**: Возможность установки максимальной частоты кадров.
- **Зацикливание**: Режим бесконечного повтора видео.
- **Очистка терминала**: Автоматическая очистка после завершения.

## Требования

- Python 3.6 или выше
- Установленные библиотеки: opencv-python, numpy
- Терминал с поддержкой True Color (например, современные версии GNOME Terminal, Konsole, iTerm2)

## Установка

1. Клонируйте репозиторий или скачайте файлы.
2. Установите зависимости:

   ```bash
   pip install -r requirements.txt
   ```

   Или вручную:

   ```bash
   pip install opencv-python numpy
   ```

## Использование

Базовый запуск:

```bash
python3 main.py путь_к_видео.mp4
```

### Опции командной строки

- `--fps <число>`: Ограничить частоту кадров (по умолчанию - оригинальная FPS видео).
- `--loop`: Зациклить воспроизведение.
- `--no-resize`: Отключить автоматическое изменение размера окна терминала.

### Примеры

Запуск с ограничением FPS до 15:

```bash
python3 main.py video.mp4 --fps 15
```

Зацикленное воспроизведение:

```bash
python3 main.py video.mp4 --loop
```

Без изменения размера окна:

```bash
python3 main.py video.mp4 --no-resize
```

## Управление

- Для выхода нажмите `Ctrl+C`.
- Во время воспроизведения отображается прогресс-бар с текущим временем, FPS и размером ASCII.
